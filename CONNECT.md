# Как подключиться к лобби

Каждый запускает Broken Phone 0.8 на своём компьютере. Отдельный аккаунт игры не нужен.

## Через Steam

1. Все участники запускают Steam и входят в свои обычные профили, затем открывают `BrokenPhone.exe`.
2. Комната создаётся автоматически. Ведущий выбирает в «Подключении» **Steam · без VPN**. Если этого варианта нет, нужно нажать «Подключить Steam» в настройках и дождаться создания комнаты.
3. Ведущий нажимает «Пригласить друзей». Откроется список друзей онлайн; кнопка «Пригласить» отправляет приглашение через Steam. Друг сначала запускает Broken Phone, затем принимает приглашение.
4. Альтернатива: «Копировать» сохраняет полную ссылку `steam://joinlobby/480/ID_ЛОББИ/ID_ВЕДУЩЕГО`. Друг вставляет её в «Войти в комнату». Один шестизначный код не подключает к Steam-комнате.
5. Ведущий выбирает пак из настроенной папки или Steam Workshop. Все нажимают «Я готов», затем ведущий запускает раунд. После нажатия «Начать озвучку» сначала появляется общая загрузка пака. Недостающие файлы передаются, проверяются и сохраняются в Packs; запись включается только после готовности всех участников. Видео и записи передаются через Steam Networking Sockets; Radmin и открытие TCP-порта для этого режима не требуются.

Используется тестовый App ID **480 (Spacewar)**. В Steam может отображаться Spacewar. У всех участников должен совпадать `steam_appid.txt`. Этот режим предназначен для разработки; собственный выпуск в Steam потребует собственного App ID. Приглашение в запущенную Broken Phone обрабатывается игрой; запуск нашего EXE из библиотеки Steam на App ID 480 не настроен.

При подключённом Steam игра использует настоящее имя профиля. Вход в SteamCMD не нужен для уже скачанных паков из папки. Папку с коллекцией выбирает ведущий; остальные получают недостающие файлы перед раундом.

## Через LAN или Radmin VPN

1. Для интернета участники подключаются к одной сети Radmin VPN; в общей локальной сети VPN не нужен. [Инструкция Radmin VPN](https://www.radmin-vpn.com/help/).
2. Ведущий выбирает в «Подключении» адрес Radmin или общей локальной сети, затем нажимает «Копировать». Получится приглашение вида `26.12.34.56:47770/ABC123`.
3. Друг запускает игру, нажимает «Войти в комнату» и вставляет приглашение целиком. Для этого режима Steam не требуется.

Если LAN/Radmin не подключается, проверьте общую сеть, адрес и разрешение BrokenPhone.exe в брандмауэре. Порт по умолчанию TCP 47770; при занятом порте выбирается другой, указанный в приглашении.

## Раунд и просмотр

Предыдущую реплику и оригинал можно прослушать по желанию. Пока один игрок записывает, остальные видят очередь. После последней реплики ведущий монтирует общий ролик; после подготовки видео у всех оно запускается автоматически. Пауза, перемотка и повтор ведущего применяются у всех. Каждый может сохранить MP4.

Кнопка «Вернуться в лобби» удалена. Во время записи и монтажа вкладка «Лобби» недоступна; на экране готового видео ведущий возвращает всех через верхнюю вкладку «Лобби».

Загрузка новых материалов Workshop остаётся отдельной функцией ведущего: доступ к пакам Dub Together определяется разрешениями Steam. Это не связано с регистрацией в сетевой комнате.

Паки можно заранее скачать в мастерской по одному либо выбрать несколько. Скачивание не выбирает пак в лобби. Кнопка «Выбрать в лобби» отдельно назначает готовый пак; обложка и числа реплик и ролей сразу появляются у всех. Для скачивания через SteamCMD ведущему может потребоваться отдельный вход с доступом к Dub Together; App ID 480 этих прав не даёт. Гостям вход в SteamCMD не нужен.
